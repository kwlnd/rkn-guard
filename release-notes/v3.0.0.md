## Один бинарник вместо баш-меню

Меню `rkn` на 800 строк баша заменено подкомандами `rkn-guard`: `install`, `update`,
`status`, `ban`/`unban`/`bans`, `sources`, `schedule`, `stats`, `logs`, `upgrade`,
`uninstall`. `rkn` остаётся ссылкой на `rkn-guard`. Встроенные списки, расписание,
ручные баны и self-update теперь в Go; бинарник работает без скриптов.

Исправлено:

- UFW больше не ставится и не включается. Раньше установщик ставил `ufw`, а `full`
  делал `ufw --force enable` — на сервере с выключенным UFW это закрывало все порты, кроме SSH.
  Без активного UFW цепочка подключается к INPUT и поднимается при загрузке `rkn-guard restore`.
- Цепочка всегда стоит первым правилом INPUT: раньше при активном UFW её обходили
  `ACCEPT`, которые VPN-панели ставят в INPUT до цепочек UFW.
- Ручные баны переживают обновление списков (раньше терялись при первом `update`), работают для IPv6.
- Пересекающиеся подсети разных списков схлопываются: ~4400 записей → ~2600 без изменения покрытия.
- Наборы заполняются одним `ipset restore`, а не процессом на каждую подсеть.
- `status` считает отброшенные пакеты по правилам DROP, а не по LOG с лимитом 10/мин.
- `install.sh` и `upgrade` сверяют sha256 с `checksums.txt`.

Новые встроенные списки: Censys, Shodan, Shadowserver и ONYPHE (OpenFilters/internet-scanners).
Выключаются как обычно: `rkn-guard sources disable b10`.

Переход со старой версии: `sudo rkn-guard install` переносит баны, расписание,
настройки списков и переводит таймер на новый бинарник.
